# Security Policy — SPManchester Private Limited

SPManchester Private Limited takes the security of our open-source software, digital products, and client solutions seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within ContentGrid or any associated module, please do **NOT** open a public issue.

Instead, please send an encrypted or direct email to our security team:
- **Email:** info@spmanchester.com
- **Subject:** `[SECURITY] ContentGrid Vulnerability Report - <Brief Title>`

Please include:
1. A description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the behavior.
3. Affected components, endpoints, or dependencies.
4. Suggestions for mitigation if available.

## Our Security Commitment

- **Acknowledgment:** Within 48 business hours.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Advisory Release:** Coordinated with the reporter before public disclosure.
- **Attribution:** We are pleased to acknowledge responsible disclosures in our release notes and hall of contributors.
